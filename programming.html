01 / DATABASES AND WEB SYSTEMS

FOOD
PANTRY
PROJECT

Role — Programmer
Program — HTML / ASP.NET / Razor Pages
Focus — Databases for FUMC Conway Food Pantry

For this project my team was focused on creating a database for the FUMC Conway food bank to track both the stock of the items available and those who receive assistance. I was responsible for the databases and authentication. I created the databases for the Users, Roles, Community Members, and Applications. I used these roles to create role-base authentication. I also worked on connecting pages, such as linking the order page to the inventory and edit box page so that they can be used in sync. This project was then passed on to another team to complete, our version can be found here.

02 / GAME DESIGN

SHADOW
WALKER
PROJECT

Role — Programmer
Program — Unity
Focus — Educational game to teach movement of the sun

For this project my team was focused on creating a game for local elementary schoolers. This game is a level based puzzle solver, each level in the beginning has a season and the character controls the time of day. My role in this project included menu and level design and sun and shadow movement. This project was then passed on to another team to complete, our version can be found here.

03 / APP DESIGN

HOCKEY EVALUATION
MOBILE APP

Role — Programmer
Program — Dart
Focus — Hockey goaltender evaluation app

For this project my team was focused on creating a hockey goaltender evaluation app. This app allows hockey coaches and scouts to rate youth hockey goaltenders on their ability on the ice to evaluate, compare, and see their players' progress. For this project I created most of the front end to connect our app together. I was also responsible for implementing firebase in our app. This project was then passed on to another team to complete, our version can be found here.
